# 🏥 QuickAdmit

QuickAdmit is a Full-Stack Smart Hospital Management & Bed Booking System developed to simplify hospital services and improve patient accessibility.

---

## 🚀 Live Demo

🔗 https://quickadmit.onrender.com

---

## 💻 Tech Stack

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Deployment

* Render
* GitHub

---

## ✨ Features

* 🔐 Login & Signup Authentication
* 🏥 Hospital Bed Booking
* 🛏 ICU / Shared / Private Bed Availability
* 📅 Appointment Booking
* 🚑 Ambulance Service
* 🤖 AI Health Assistant Chatbot
* 🌙 Dark Mode
* 📱 Responsive Design
